### HÌNH 2.2: SƠ ĐỒ HOẠT ĐỘNG QUY TRÌNH TÍNH GIÁ MAY ĐO RÈM THEO M2
```mermaid
flowchart TD
    Start([Bắt đầu]) --> Step1[Chọn loại rèm, mẫu vải, phụ kiện, kiểu may]
    Step1 --> Step2[Nhập chiều rộng W và chiều cao H theo mét]
    Step2 --> Decision1{W > 0 và H > 0?}
    
    Decision1 -- Không --> Error1[Báo lỗi kích thước không hợp lệ] --> Step2
    Decision1 -- Có --> CalcArea[Tính Diện tích S = W * H]
    
    CalcArea --> Decision2{S < S_min 1.0 m2?}
    Decision2 -- Có --> ApplyMin[Gán S_tinh_gia = S_min 1.0 m2]
    Decision2 -- Không --> ApplyReal[Gán S_tinh_gia = S]
    
    ApplyMin --> CalcFabric[Tính định mức mét vải = W * He_so_nhun 2.5]
    ApplyReal --> CalcFabric
    
    CalcFabric --> CalcCost[Tổng tiền = S_tinh_gia * Don_gia_m2 + Phu_kien + Cong_lap_dat]
    CalcCost --> Display[Hiển thị bảng phân tích chi phí trực quan]
    Display --> End([Kết thúc])
```

### HÌNH 5.2: SƠ ĐỒ TUẦN TỰ QUY TRÌNH ĐẶT MAY RÈM VÀ THANH TOÁN MOMO
```mermaid
sequenceDiagram
    autonumber
    actor Customer as Khách hàng
    participant UI as Giao diện Web (React)
    participant API as Backend API (OrderService)
    participant MoMo as MoMo Payment Gateway
    participant DB as CSDL PostgreSQL

    Customer->>UI: Nhập kích thước (W, H), chọn mẫu vải & phụ kiện
    UI->>API: POST /api/v1/curtain/calculate-price
    API-->>UI: Bảng phân tích chi phí may đo chi tiết
    Customer->>UI: Nhấn "Đặt may & Thanh toán cọc"
    UI->>API: POST /api/v1/orders/checkout (OrderDTO)
    API->>DB: Ghi bản ghi Orders (Status: PENDING_PAYMENT)
    API->>MoMo: Gọi API /v2/gateway/api/create (orderId, amount)
    MoMo-->>API: Trả về payUrl & qrCodeUrl
    API-->>UI: Trả về MoMo QR Code URL
    UI-->>Customer: Hiển thị Popup QR Code MoMo
    Customer->>MoMo: Mở App MoMo quét mã và xác nhận chuyển tiền
    MoMo->>API: Webhook IPN POST /api/v1/payments/momo-ipn (Signature, resultCode=0)
    API->>API: Xác thực chữ ký bí mật (HMAC SHA256)
    API->>DB: UPDATE Orders SET status='PAID_DEPOSIT', payment_status='PAID'
    API-->>MoMo: HTTP 204 No Content (Xác nhận đã nhận IPN)
    API-->>UI: Gửi thông báo WebSocket / Polling: Thanh toán thành công!
    UI-->>Customer: Hiển thị màn hình Đặt may thành công & Mã vận đơn
```

### HÌNH 5.3: SƠ ĐỒ TUẦN TỰ QUY TRÌNH ĐĂNG KÝ VÀ KHẢO SÁT ĐO ĐẠC TẠI NHÀ
```mermaid
sequenceDiagram
    autonumber
    actor Customer as Khách hàng
```
